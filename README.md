# Grace Church Website

A modern, responsive church website built using **HTML5**, **CSS3**, **JavaScript**, and **Bootstrap 5**.  
Designed with a clean **white, blue, and gray** theme, this project provides essential pages for a church’s digital presence, including sermons, events, ministries, and live streaming.

---

## ✨ Features

- Responsive layout using Bootstrap 5
- Clean and modern UI design
- Subtle CSS animations for improved user experience
- Multi-page structure
- Mobile-first and cross-browser compatible

### Included Pages
- Home
- About Us
- Sermons
- Events
- Ministries
- Live Stream (YouTube embed supported)
- Contact Us
